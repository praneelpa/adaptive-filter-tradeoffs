# Accuracy-Constrained Computational Tradeoffs of LMS, NLMS, and RLS under Correlated Inputs

This repository contains the MATLAB simulation code, raw data, and LaTeX source code for the paper: 
**"Accuracy-Constrained Computational Tradeoffs of LMS, NLMS, and RLS under Correlated Inputs"** by Praneel Patel.

## Overview
This codebase reproduces the full experimental suite comparing the total computational cost required for LMS, NLMS, and RLS adaptive filters to reach a strictly enforced, shared accuracy target under varying input correlations and filter lengths. 

## Requirements
* **MATLAB:** The code was developed and tested on MATLAB R2026a. 
* No specialized toolboxes are required; the simulations use standard MATLAB functions.

## Repository Structure
* `run_all.m`: The master script. Running this single file executes all simulations, calculates the bootstrap confidence intervals, and generates all figures and tables used in the paper.
* `results/`: Contains the generated `numbers.tex` file, which dynamically feeds the simulation metrics directly into the LaTeX document.
* `figs/`: Contains the PDF figures generated by the scripts.
* `tables/`: Contains the LaTeX table fragments generated by the scripts.
* `paper.tex`: The main LaTeX source code for the manuscript.

## Usage
To reproduce the results:
1. Clone or download this repository.
2. Open MATLAB and navigate to the repository folder.
3. Type `run_all` in the command window and press Enter.

**Note on execution time:** The master script runs extensive bootstrap resampling (1,000 resamples per condition) to generate the 95% confidence intervals. Depending on your hardware, this may take some time to complete.
